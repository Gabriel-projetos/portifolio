# Gabriel Motta Rossetto | Portfólio

Site pessoal com foco em **engenharia de bancos de dados** e **UX/UI design**, feito para apresentar meus projetos e minha disponibilidade para estágio e freelance.

🔗 **Demo:** [link-do-deploy]

![Preview do site](./docs/preview.png)

## Funcionalidades

- Interface bilíngue (português e inglês)
- Modo claro e modo escuro
- Fundo animado em SVG com Framer Motion
- Carrossel infinito de tecnologias
- Layout responsivo
- Páginas: Trabalhe comigo, Sobre mim e Contato

## Tecnologias

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- [Framer Motion](https://www.framer.com/motion/)
- [React Router](https://reactrouter.com/)
- [React Icons](https://react-icons.github.io/react-icons/)

## Como rodar localmente

Pré-requisito: [Node.js](https://nodejs.org/) 18 ou superior.

```bash
# clone o repositório
git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git

# entre na pasta
cd NOME-DO-REPO

# instale as dependências
npm install

# rode em modo de desenvolvimento
npm run dev
```

O site abre em `http://localhost:5173`.

Para gerar a versão de produção:

```bash
npm run build
```
